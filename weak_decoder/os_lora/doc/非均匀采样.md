# 基本推导
先设：

$ N=2^{\mathrm{SF}},
\qquad
R=\mathrm{OS} $

一个过采样 LoRa symbol 有：

$ NR $

个采样点。过采样 dechirp 后的序列记为：

$ z[n],
\qquad
n=0,\dots,NR-1 $

它的全长 $ NR $-point DFT 定义为：

$ Z[K]
=
\sum_{n=0}^{NR-1}
z[n]e^{-j2\pi Kn/(NR)} $

对应的反变换是：

$ z[n]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi Kn/(NR)} $

---

## 取第 $ q $ 路 branch
现在取第 $ q $ 路 branch：

$ z_q[p]
=
z[pR+q],
\qquad
p=0,\dots,N-1 $

也就是每隔 $ R $ 个点取一个，第 $ q $ 路从 offset $ q $ 开始取。

对这一路做 $ N $-point DFT：

$ Y_q[m]
=
\sum_{p=0}^{N-1}
z[pR+q]e^{-j2\pi mp/N} $

接下来把 $ z[pR+q] $ 用全长 DFT 的反变换代进去：

$ z[pR+q]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi K(pR+q)/(NR)} $

所以：

$ Y_q[m]
=
\sum_{p=0}^{N-1}
\left[
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi K(pR+q)/(NR)}
\right]
e^{-j2\pi mp/N} $

把求和顺序换一下：

$ Y_q[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi Kq/(NR)}
\sum_{p=0}^{N-1}
e^{j2\pi KpR/(NR)}
e^{-j2\pi mp/N} $

注意：

$ \frac{KpR}{NR}
=
\frac{Kp}{N} $

所以里面关于 $ p $ 的部分变成：

$ \sum_{p=0}^{N-1}
e^{j2\pi Kp/N}
e^{-j2\pi mp/N}
=
\sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N} $

这个求和是一个标准几何级数：

$ \sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N}
=
\begin{cases}
N, & K-m \equiv 0 \pmod{N}\\
0, & \text{otherwise}
\end{cases} $

也就是说，只有当：

$ K
=
m+\ell N $

时才会留下来。其中：

$ \ell=0,1,\dots,R-1 $

因为 $ K $ 的范围是 $ 0,\dots,NR-1 $。

于是原式只剩下这些 $ K=m+\ell N $ 的项：

$ Y_q[m]
=
\frac{1}{NR}
\sum_{\ell=0}^{R-1}
Z[m+\ell N]
e^{j2\pi q(m+\ell N)/(NR)}
\cdot N $

前面的系数是：

$ \frac{N}{NR}
=
\frac{1}{R} $

所以得到：

$ Y_q[m]
=
\frac{1}{R}
\sum_{\ell=0}^{R-1}
Z[m+\ell N]
e^{j2\pi q(m+\ell N)/(NR)} $

** 折叠周期是 N 个 full-FFT bin，对应标准 LoRa Nyquist-rate 解调下的一整个符号频率网格。  **

---

## 这个式子的物理含义
这个式子的物理含义是：

$ \boxed{
\text{第 }q\text{ 路 branch 的 bin }m
=
\text{全 }NR\text{ 点频谱中 }m,m+N,m+2N,\dots,m+(R-1)N\text{ 的线性组合}
} $

也就是说，branch DFT 不是凭空生成一个新频谱，而是把过采样全频谱中**相隔 **$ N $** 个 bin 的频谱切片 alias 到一起。**

---

## 放回 LoRa 场景
如果** dechirp 后真实信号在全长 **$ NR $**-point 频谱里主要落在：**

$ K=k $

那么对 branch bin $ m=k $：

$ Y_q[k]
\approx
\frac{1}{R}
Z[k]e^{j2\pi qk/(NR)} $

但是这个式子，**在SNR比较低的时候k+lN那些位置可能无可避免的会出现很多高度不容忽视的噪声，所以这个近似将不成立**

所以不同 branch 之间差的就是这个确定性相位：

$ e^{j2\pi qk/(NR)} $

因此你要相干叠加，就乘反向相位：

$ Y_q[k]e^{-j2\pi qk/(NR)} $

再求和：

$ S[k]
=
\sum_{q=0}^{R-1}
Y_q[k]e^{-j2\pi qk/(NR)} $

这就是你现在“过采样拆 branch，然后相位对齐叠加”的数学根。

# 非均匀采样
## 基本推导
定义**第 **$ b $** 路 branch 的普通 **$ N $**-point DFT**：

$ Y_b[m]
=
\sum_{p=0}^{N-1}
z[Rp+c_b[p]]
e^{-j2\pi mp/N} $

令 full $ NR $-point DFT 为：

$ Z[K]
=
\sum_{n=0}^{NR-1}
z[n]e^{-j2\pi Kn/(NR)} $

反变换为：

$ z[n]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi Kn/(NR)} $

代入 $ Y_b[m] $：

$ Y_b[m]
=
\sum_{p=0}^{N-1}
\left[
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]e^{j2\pi K(Rp+c_b[p])/(NR)}
\right]
e^{-j2\pi mp/N} $

交换求和顺序：

$ Y_b[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]
\sum_{p=0}^{N-1}
e^{j2\pi K(Rp+c_b[p])/(NR)}
e^{-j2\pi mp/N} $

因为：

$ \frac{K Rp}{NR}
=
\frac{Kp}{N} $

所以：

$ Y_b[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]
\sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N}
e^{j2\pi Kc_b[p]/(NR)} $

这就是更一般的式子。

也可以写成：

$ Y_b[m]
=
\frac{1}{NR}
\sum_{K=0}^{NR-1}
Z[K]H_b(m,K) $

其中：

$ H_b(m,K)
=
\sum_{p=0}^{N-1}
e^{j2\pi (K-m)p/N}
e^{j2\pi Kc_b[p]/(NR)} $

这个 $ H_b(m,K) $ 就是你的非均匀 branch pattern 对 full-spectrum bin $ K $ 到 branch bin $ m $ 的混合权重。

也就是说，非均匀 branch 不再像固定 offset branch 那样，只把：

$ K=m+\ell N $

这些 bin 精确折叠到 $ m $。而是通过<font style="background-color:#FBDE28;"> </font>$ H_b(m,K) $**<font style="background-color:#FBDE28;"> 给每个 full-spectrum bin </font>**$ K $**<font style="background-color:#FBDE28;"> 一个 pattern-dependent 的混合权重。</font>**

因此可以把它理解成：

> 固定 offset branch 的混合权重是规则 aliasing；  
非均匀 branch 的混合权重是由 $ c_b[p] $ 决定的非规则投影。
>

我们不是凭空制造新的物理副本，而是**从过采样 IQ 中构造多个不均匀采样视角**。每个视角都可以恢复或投影出一个候选 LoRa tone 的观测结果。真实 bin 在这些视角下应该稳定，而噪声假峰和 alias 泄漏在不同 pattern 下会表现不一致。因此，这些“重构副本”的价值不是增加独立能量来源，而是提供多视角一致性和假峰去相关。  

## 不同采样pattern
非均匀 pattern 的采样点是：

$ n_{b,p}
=
Rp+c_b[p] $

如果要测试候选 bin $ m $，**正确的 matched projection 应该写成**：

$ Y_b[m]
=
\sum_{p=0}^{N-1}
z[Rp+c_b[p]]
e^{-j2\pi m(Rp+c_b[p])/(NR)} $

用候选 bin $ m $ 去做 matched projection：

$ Y_b[m]
=
\sum_{p=0}^{N-1}
z[Rp+c_b[p]]
e^{-j2\pi m(Rp+c_b[p])/(NR)} $

真实信号代进去。假设真实 bin 是 $ K $，dechirp 后：

$ z[n]
=
x e^{j2\pi Kn/(NR)}
+
v[n] $

:::info
其中，x的含义为：$ x
=
\text{发射幅度}
\times
\text{信道复增益}
\times
\text{公共相位旋转} $

更具体地，可以写成：

$ x
=
A\cdot h\cdot e^{j\phi} $

其中：

+ $ A $：发射信号幅度；
+ $ h $：信道复增益；
+ $ e^{j\phi} $：公共相位旋转。

:::

于是：

$ Y_b[m]
=
x
\sum_{p=0}^{N-1}
e^{j2\pi K(Rp+c_b[p])/(NR)}
e^{-j2\pi m(Rp+c_b[p])/(NR)}
+
\eta_b[m] $

合并指数项：

$ Y_b[m]
=
x
\sum_{p=0}^{N-1}
e^{j2\pi(K-m)(Rp+c_b[p])/(NR)}
+
\eta_b[m] $

定义真实 bin $ K $ 对候选 bin $ m $ 的响应：

$ \boxed{
H_b(m,K)
=
\sum_{p=0}^{N-1}
e^{j2\pi(K-m)(Rp+c_b[p])/(NR)}
} $

所以：

$ \boxed{
Y_b[m]
=
xH_b(m,K)
+
\eta_b[m]
} $

其中 $ H_b(m,K) $ 就是：**第 **$ b $** 条非均匀 pattern 下，真实 bin **$ K $** 对候选 bin **$ m $** 的响应。**

## LoRa corrected非均匀采样响应
实际做的时候，不先算 $ Z[\kappa] $，再用 full DFT basis 分析。

我代码里**直接在时域上做：**

$ z[n_{b,p}]
\times
\text{候选模板的共轭} $

这时候 $ K $ 不是 full DFT bin，而是 LoRa raw symbol bin。**理想 dechirp 后的 LoRa bin **$ K $** **可以写成：**s的物理含义是**：LoRa 符号 K 经过 dechirp 之后，**在理想无噪声、无 CFO、无采样偏差情况下的理论时域值。**

$ s_K[Rp+q]
=
e^{j2\pi K(Rp+q)/(NR)}
\rho_K(p,q) $

其中：

$ \rho_K(p,q)
=
\begin{cases}
1, & K=0,\\
1, & p<N-K,\\
e^{-j2\pi q/R}, & p\ge N-K.
\end{cases} $

$ s_m[Rp+q]

matched filter 要乘候选模板的共轭：

$ s_m^*[Rp+q]
=
e^{-j2\pi m(Rp+q)/(NR)}
\rho_m^*(p,q) $

于是：

$ \tau_m(p,q)
=
\rho_m^*(p,q) $

也就是：

$ \tau_m(p,q)

\begin{cases}

1, & p<N-m,\\

\end{cases} $

$ H_b^{\mathrm{LoRa}}(m,K)

\sum_{p=0}^{N-1}

代入后：

$ \boxed{

=
\sum_{p=0}^{N-1}
e^{j2\pi(K-m)(Rp+c_b[p])/(NR)}
\rho_K(p,c_b[p])
\tau_m(p,c_b[p])
} $

这个式子不是 full-DFT 的 $ H $，这个式子回答的是：**如果真实 LoRa 符号是 K，我用候选 LoRa 模板 m 去匹配，它会输出多大？  **

# 什么是白化？
白化，最直观一句话：

$ \boxed{
\text{白化就是把“相关、有强弱差异的噪声”变成“互不相关、方差相同的标准噪声”。}
} $

在你现在这个问题里，我们有：

$ \mathbf{y}
=
\mathbf{a}x+\boldsymbol{\eta} $

其中：

$ \mathbb{E}
\left[
\boldsymbol{\eta}\boldsymbol{\eta}^H
\right]
=
\mathbf{C} $

这里 $ \mathbf{C} $ 是噪声协方差矩阵。它告诉你几件事：

第一，每个 branch 的噪声强不强；

第二，不同 branch 的噪声是不是相关；

第三，哪些 branch 其实是重复信息，不能当成独立副本乱叠加。

---

## 一个简单例子
比如你有两个观测：

$ \mathbf{y}
=
\begin{bmatrix}
y_1\\
y_2
\end{bmatrix}
=
\mathbf{a}x+\boldsymbol{\eta} $

如果噪声协方差是：

$ \mathbf{C}
=
\begin{bmatrix}
1 & 0\\
0 & 1
\end{bmatrix} $

说明两个 branch 的噪声独立，而且强度一样。这时候你直接相干叠加是合理的。

但如果：

$ \mathbf{C}
=
\begin{bmatrix}
1 & 0.95\\
0.95 & 1
\end{bmatrix} $

**说明两个 branch 的噪声高度相关**。它们看起来是两个输出，**但本质上噪声几乎一样。**这个时候你不能把它们当成两个独立副本，否则会高估增益。白化就是专门处理这个问题的。

---

## 白化在数学上做了什么？
数学上，白化就是找一个矩阵 $ \mathbf{C}^{-1/2} $，然后左乘观测：

$ \tilde{\mathbf{y}}
=
\mathbf{C}^{-1/2}\mathbf{y} $

代入：

$ \tilde{\mathbf{y}}
=
\mathbf{C}^{-1/2}\mathbf{a}x
+
\mathbf{C}^{-1/2}\boldsymbol{\eta} $

定义：

$ \tilde{\mathbf{a}}
=
\mathbf{C}^{-1/2}\mathbf{a} $

$ \tilde{\boldsymbol{\eta}}
=
\mathbf{C}^{-1/2}\boldsymbol{\eta} $

于是：

$ \tilde{\mathbf{y}}
=
\tilde{\mathbf{a}}x+\tilde{\boldsymbol{\eta}} $

:::info
关键是新的噪声协方差变成（这里C得是一个共轭转置对称矩阵，且正定）：

$ \mathbb{E}
\left[
\tilde{\boldsymbol{\eta}}
\tilde{\boldsymbol{\eta}}^H
\right]
=
\mathbf{I} $

也就是说，白化之后噪声变成了标准白噪声：

$ \boxed{
\text{不相关，且每个方向上的方差都是 }1
} $

:::

## 怎么得到 $ \mathbf{C}^{-1/2} $？
如果：

$ \mathbf{C}
=
\mathbf{U}\boldsymbol{\Lambda}\mathbf{U}^H $

那么：

$ \mathbf{C}^{-1/2}
=
\mathbf{U}
\boldsymbol{\Lambda}^{-1/2}
\mathbf{U}^H $

其中：

$ \boldsymbol{\Lambda}^{-1/2}
=
\operatorname{diag}
\left(
\frac{1}{\sqrt{\lambda_1}},
\frac{1}{\sqrt{\lambda_2}},
\dots
\right) $

直觉上就是：

$ \boxed{
\text{哪个方向噪声大，就压小；哪个方向噪声小，就保留；重复方向会被削掉。}
} $

$ \boxed{
\text{保留非零特征值对应的特征方向，丢掉零特征值对应的重复方向}
} $

这里**处理的也不是某几条具体的 pattern 行或列，而是由多条 pattern 线性组合形成的方向。**

假设：

$ \mathbf{C}
=
\mathbf{U}
\boldsymbol{\Lambda}
\mathbf{U}^H $

其中：

$ \boldsymbol{\Lambda}
=
\operatorname{diag}
\left(
\lambda_1,\ldots,\lambda_r,0,\ldots,0
\right) $

那么伪逆只使用满足：

$ \lambda_1,\ldots,\lambda_r>0 $

的非零特征值，得到：

$ \mathbf{C}^{+}
=
\mathbf{U}_r
\boldsymbol{\Lambda}_r^{-1}
\mathbf{U}_r^H $

这相当于把原来的 $ B $ 条 branch 压缩成 $ r $ 个真正独立的有效方向：

$ \boxed{
B\text{ 条表面观测}
\quad\longrightarrow\quad
r=\operatorname{rank}(\mathbf{C})
\text{ 个有效噪声自由度}
} $

例如，两条 pattern 完全相同：

$ \mathbf{C}
=
\begin{bmatrix}
1 & 1\\
1 & 1
\end{bmatrix} $

它的特征值为：

$ \lambda_1=2,
\qquad
\lambda_2=0 $

对应的两个特征方向分别为：

$ \mathbf{u}_1
=
\frac{1}{\sqrt{2}}
\begin{bmatrix}
1\\
1
\end{bmatrix},
\qquad
\mathbf{u}_2
=
\frac{1}{\sqrt{2}}
\begin{bmatrix}
1\\
-1
\end{bmatrix} $

其中：

+ $ \mathbf{u}_1 $：两条 pattern 的**共同信息方向（两条pattern的和）**；
+ $ \mathbf{u}_2 $：两条 pattern 的**差异方向（把两条pattern输出相减形成的观测）**。

但由于两条 pattern 完全相同，它们的差始终为零：

$ y_1-y_2=0 $

因此，$ \mathbf{u}_2 $ 是零特征值方向**，伪逆会直接将该方向的逆权重设为零；保留 **$ \mathbf{u}_1 $** 就已经包含了全部有效信息。**

它们**表面上增加了观测数量，但并没有增加新的自由度，因此删除重复信息不会造成有效信息损失**。

不过需要注意：

$ \boxed{
\text{伪逆删除的是冗余方向，不一定等价于删除某几条具体的 pattern}
} $

因为一个特征方向通常是多条 pattern 的线性组合，不能简单理解成“把第 3、7、9 条 pattern 扔掉”。

任意删除某条 pattern，可能会改变：

+ 有效子空间；
+ 协方差矩阵的条件数；
+ 信号方向 $ \mathbf{a} $ 与低噪声方向之间的对齐程度。

更准确的说法是：

> 即使构造了很多 pattern，只要它们之间存在线性重复，协方差矩阵就会降秩。伪逆会自动忽略零特征值对应的冗余组合，只在非零特征值张成的有效子空间中进行白化和 GLS 合并。因此，表面上的 pattern 数量可以很多，但最终真正参与检测的是由协方差矩阵的秩决定的有效方向数。
>

此外，协方差矩阵的特征值都满足：

$ \lambda_i\geq 0 $

但并不是所有“非负特征值”都会进入伪逆，而是：

$ \lambda_i>0 $

的方向才会取倒数；对于：

$ \lambda_i=0 $

的方向，伪逆中的对应值被设为零。

也就是说：

$ \lambda_i^{+}
=
\begin{cases}
\dfrac{1}{\lambda_i},
& \lambda_i>0,\\[6pt]
0,
& \lambda_i=0.
\end{cases} $

实际数值计算中，**特别小的特征值通常也会被视为近似零，因为直接取倒数会严重放大协方差估计误差。**

另一种更常见的处理方式是加入对角加载：

$ \mathbf{C}_{\lambda}
=
\mathbf{C}
+
\lambda\mathbf{I} $

使每个特征值变为：

$ \lambda_i
\longrightarrow
\lambda_i+\lambda $

从而避免对接近零的特征方向赋予异常大的权重。

## 放回非均匀采样问题
每个 pattern 都给你一个输出：

$ Y_b[m]
=
xH_b(m,K)+\eta_b[m] $

把它们堆起来：

$ \mathbf{y}[m]
=
x
\begin{bmatrix}
H_1(m,K)\\
H_2(m,K)\\
\vdots\\
H_B(m,K)
\end{bmatrix}
+
\boldsymbol{\eta}[m] $

也就是：

$ \mathbf{y}[m]
=
\mathbf{a}x+\boldsymbol{\eta} $

但是不同 pattern 的噪声不是天然独立的。

因为它们可能用了重叠采样点，或者来自同一个过采样接收链，所以：

$ \mathbb{E}
\left[
\boldsymbol{\eta}\boldsymbol{\eta}^H
\right]
=
\mathbf{C}
\neq
\mathbf{I} $

白化的作用就是：

$ \boxed{
\text{不要把这些 pattern 当成“同等独立副本”，而是先根据噪声相关性重新正交化和归一化。}
} $

然后再做 matched filter。

---

## 在这个问题里，白化的意义是什么？
白化的意义非常关键：

$ \boxed{
\text{它是在判断：这些非均匀 pattern 到底提供了多少真正独立的有效观测。}
} $

如果很多 pattern 只是重复看了同一份噪声，白化后不会给你虚假的增益。

如果某些 pattern 真的提供了新的、低相关的观测方向，白化后它们会被保留下来，带来有效增益。

---

## 一句话总结
可以把白化理解成一句人话：

$ \boxed{
\text{先把观测空间里的噪声地形抹平，再看信号往哪个方向冒出来。}
} $

不白化时，你是在一个噪声高低不平、方向相关的空间里直接量信号，很容易被相关噪声骗。

白化后，噪声各方向都一样公平，这时候再做相关检测，才是真正意义上的最优合并。

# 实验1：噪声向量相干
噪声项：$ \boldsymbol{\eta}
=
\begin{bmatrix}
\eta_1\\
\eta_2\\
\vdots\\
\eta_B
\end{bmatrix} $不是独立的。因为**不同非均匀 pattern 会复用同一批原始采样点。**

于是噪声协方差是：$ \mathbf{C}
=
\mathbb{E}
\left[
\boldsymbol{\eta}
\boldsymbol{\eta}^{H}
\right] $（**该协方差形式默认噪声均值为0**）。沿用前面的投影矩阵记号，把第 $ b $ 条 pattern 在候选 $ m $ 下的采样权重写成 $ \mathbf{S}(m) $ 的第 $ b $ 行。$ \mathbf{S}(m) \in \mathbb{C}^{B\times NR} $

其中 $ NR $ 列对应一个 LoRa symbol 过采样 dechirp 后的 $ NR $ 个时域采样点。第 $ b $ 行的元素是：

$ [\mathbf{S}(m)]_{b,n}
=
\begin{cases}
\dfrac{1}{\sqrt{N}}s_m^*[n], & n=n_{b,p}=Rp+c_b[p]\text{ for some }p,\\
0, & \text{otherwise}.
\end{cases} $

于是噪声向量可以写成：$ \boldsymbol{\eta}(m)
=
\mathbf{S}(m)\mathbf{v}_{\mathrm{samp}} $其中：$ \mathbf{v}_{\mathrm{samp}}
=
\begin{bmatrix}
v[0]\\
v[1]\\
\vdots\\
v[NR-1]
\end{bmatrix} $表示**同一个 symbol 的 **$ NR $** 个采样点上叠加的噪声分量。**

:::info
**如果原始采样噪声是白噪声**：$ \mathbb{E}[\mathbf{v}_{\mathrm{samp}}\mathbf{v}_{\mathrm{samp}}^H]
=
\sigma^2\mathbf{I}_{NR} $，那么：

$ \mathbf{C}
=
\mathbb{E}
\left[
\boldsymbol{\eta}\boldsymbol{\eta}^H
\right]
=
\mathbb{E}
\left[
\mathbf{S}(m)\mathbf{v}_{\mathrm{samp}}\mathbf{v}_{\mathrm{samp}}^H\mathbf{S}^H(m)
\right]
=
\sigma^2\mathbf{S}(m)\mathbf{S}^H(m) $

如果把噪声功率 $ \sigma^2 $ 归一化为 1，就得到：$ \mathbf{C}
=
\mathbf{S}(m)\mathbf{S}^H(m) $，这个矩阵的含义是：

$ C_{ij}
=
\text{第 } i \text{ 条 pattern 和第 } j \text{ 条 pattern 的噪声相关性} $

**如果两条 pattern 大量复用同样的采样点，那么：**$ |C_{ij}| $**就会很大。**

:::

## 正确的相干增益
如果噪声相关，**最佳线性合并不能简单求和**，而要用：

$ \mathbf{C}^{+} $

其中 $ \mathbf{C}^{+} $ 是伪逆。

### 最佳线性组合
最一般的线性合并就是：

$ T
=
w_1^*y_1+w_2^*y_2+\cdots+w_B^*y_B $

写成向量：$ T
=
\mathbf{w}^H\mathbf{y} $其中：$ \mathbf{w}
=
\begin{bmatrix}
w_1\\
w_2\\
\vdots\\
w_B
\end{bmatrix} $就是要选的权重。

:::info
这一部分优化的实际上是**固定候选 bin **$ m $** 下、pattern 维度上的输出 SNR，即决定各条 branch 应该如何加权，才能使该候选列中的目标响应尽可能高于加性噪声。**

由于这一优化只作用于完整 $ B\times N $ 输出矩阵中的一列，**它没有联合利用其他候选 bin 的响应，也没有显式优化正确候选与错误候选之间的判决间隔**。

因此，它主要解决的是：

$ \boxed{
\text{branch 级相干合并}
+
\text{加性噪声抑制}
} $

而不能直接解决：

$ \boxed{
\text{错误候选 bin 的旁瓣与泄漏抑制}
} $

更准确地说，该方法优化的是单列输出 SNR：

$ \max_{\mathbf{w}}
\frac{
|x|^2
\left|
\mathbf{w}^H\mathbf{a}(m,K_0)
\right|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
} $

但真正的符号判决依赖于正确候选与所有错误候选之间的相对关系，例如：

$ T[K_0]
>
T[m],
\qquad
\forall m\neq K_0 $

或者进一步优化判决间隔：

$ T[K_0]
-
\max_{m\neq K_0}T[m] $

:::

---

现在 pattern 输出模型是：

$ \mathbf{y}
=
\mathbf{a}x+\boldsymbol{\eta} $

$ \mathbf{y}(m)
=
\frac{x}{\sqrt{N}}
\mathbf{h}^{\mathrm{LoRa}}(m,K_0)
+
\boldsymbol{\eta}(m) $（和上面那个式子等价哈）

代入：

$ T
=
\mathbf{w}^H
\left(
\mathbf{a}x+\boldsymbol{\eta}
\right) $

所以：

$ T
=
\underbrace{\mathbf{w}^H\mathbf{a}x}_{\text{合并后的信号}}
+
\underbrace{\mathbf{w}^H\boldsymbol{\eta}}_{\text{合并后的噪声}} $

我们希望什么？**希望信号大，噪声小。**合并后的信号幅度和$ |\mathbf{w}^H\mathbf{a}| $有关。

合并后的噪声方差是（噪声功率）：$ \mathbb{E}
\left[
|\mathbf{w}^H\boldsymbol{\eta}|^2
\right]
=
\mathbf{w}^H\mathbf{C}\mathbf{w} $其中：$ \mathbf{C}
=
\mathbb{E}
\left[
\boldsymbol{\eta}\boldsymbol{\eta}^H
\right] $。所以这个合并器的输出 SNR为：

$ \boxed{
\operatorname{SNR}_{\mathrm{out}}
(\mathbf{w}\mid x)
=
\frac{
|x|^2
\left|
\mathbf{w}^H\mathbf{a}
\right|^2
}{
\mathbf{w}^H
\mathbf{C}
\mathbf{w}
}
} $

忽略 $ |x|^2 $，就是：

$ \mathrm{SNR}(\mathbf{w})
=
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
} $

:::info
**“最佳线性合并”就是：**

$ \boxed{
\max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
}
} $

**也就是在所有线性权重 **$ \mathbf{w} $** 里面，找一个让输出 SNR 最大的权重。**

:::

---

### 最优匹配能量
:::info
理论最优的匹配能量是：

$ \mathbf{a}^{H}
\mathbf{C}^{+}
\mathbf{a} $

所以我定义：

$ \mathrm{effective\_replicas}
=
\frac{
\mathbf{a}^{H}
\mathbf{C}^{+}
\mathbf{a}
}{N} $

:::

这个量的意思是：**这一堆 pattern，在正确扣掉噪声相关性以后，等效于多少条独立的 **$ \sqrt{N} $** 副本？**

---

**推导过程如下：**

目标是求：

$ \mathrm{SNR}(\mathbf{w})
=
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
} $

也就是：

$ \max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
} $

其中：

+ $ \mathbf{w} $：线性合并权重；
+ $ \mathbf{a} $：目标响应向量；
+ $ \mathbf{C} $：噪声协方差矩阵。

---

#### 先假设 $ \mathbf{C} $ 可逆
因为 $ \mathbf{C} $ 是噪声协方差矩阵，所以它是 **Hermitian 正定矩阵**，可以写成：

$ \mathbf{C}
=
\mathbf{C}^{1/2}\mathbf{C}^{1/2} $

令：

$ \mathbf{u}
=
\mathbf{C}^{1/2}\mathbf{w} $

则：

$ \mathbf{w}
=
\mathbf{C}^{-1/2}\mathbf{u} $

---

#### 先看分母
分母是：

$ \mathbf{w}^H\mathbf{C}\mathbf{w} $

代入：

$ \mathbf{w}
=
\mathbf{C}^{-1/2}\mathbf{u} $

得到：

$ \mathbf{w}^H\mathbf{C}\mathbf{w}
=
(\mathbf{C}^{-1/2}\mathbf{u})^H
\mathbf{C}
(\mathbf{C}^{-1/2}\mathbf{u}) $

因为 $ \mathbf{C} $ 是 Hermitian，所以 $ \mathbf{C}^{-1/2} $ 也是 Hermitian：

$ (\mathbf{C}^{-1/2})^H
=
\mathbf{C}^{-1/2} $

于是：

$ (\mathbf{C}^{-1/2}\mathbf{u})^H
=
\mathbf{u}^H\mathbf{C}^{-1/2} $

所以：

$ \mathbf{w}^H\mathbf{C}\mathbf{w}
=
\mathbf{u}^H
\mathbf{C}^{-1/2}
\mathbf{C}
\mathbf{C}^{-1/2}
\mathbf{u} $

而：

$ \mathbf{C}^{-1/2}
\mathbf{C}
\mathbf{C}^{-1/2}
=
\mathbf{I} $

:::info
所以：

$ \boxed{
\mathbf{w}^H\mathbf{C}\mathbf{w}
=
\mathbf{u}^H\mathbf{u}
=
\|\mathbf{u}\|^2
} $

:::

---

#### 再看分子
分子是：

$ |\mathbf{w}^H\mathbf{a}|^2 $

代入：

$ \mathbf{w}
=
\mathbf{C}^{-1/2}\mathbf{u} $

有：

$ \mathbf{w}^H\mathbf{a}
=
(\mathbf{C}^{-1/2}\mathbf{u})^H\mathbf{a} $

$ =
\mathbf{u}^H\mathbf{C}^{-1/2}\mathbf{a} $

定义：

$ \mathbf{b}
=
\mathbf{C}^{-1/2}\mathbf{a} $

:::info
于是：

$ \boxed{
|\mathbf{w}^H\mathbf{a}|^2
=
|\mathbf{u}^H\mathbf{b}|^2
} $

所以 SNR 变成：

$ \mathrm{SNR}(\mathbf{w})
=
\frac{
|\mathbf{u}^H\mathbf{b}|^2
}{
\|\mathbf{u}\|^2
} $

:::

---

#### 用柯西-施瓦茨不等式
现在用柯西-施瓦茨不等式：

$ |\mathbf{u}^H\mathbf{b}|
\leq
\|\mathbf{u}\|\|\mathbf{b}\| $

两边平方：

$ |\mathbf{u}^H\mathbf{b}|^2
\leq
\|\mathbf{u}\|^2\|\mathbf{b}\|^2 $

所以：

$ \frac{
|\mathbf{u}^H\mathbf{b}|^2
}{
\|\mathbf{u}\|^2
}
\leq
\|\mathbf{b}\|^2 $

因此最大 SNR 是：

$ \max_{\mathbf{w}}
\mathrm{SNR}(\mathbf{w})
=
\|\mathbf{b}\|^2 $

代回：

$ \mathbf{b}
=
\mathbf{C}^{-1/2}\mathbf{a} $

得到：

$ \|\mathbf{b}\|^2
=
(\mathbf{C}^{-1/2}\mathbf{a})^H
(\mathbf{C}^{-1/2}\mathbf{a}) $

$ =
\mathbf{a}^H
(\mathbf{C}^{-1/2})^H
\mathbf{C}^{-1/2}
\mathbf{a} $

因为：

$ (\mathbf{C}^{-1/2})^H
=
\mathbf{C}^{-1/2} $

所以：

$ \|\mathbf{b}\|^2
=
\mathbf{a}^H
\mathbf{C}^{-1/2}
\mathbf{C}^{-1/2}
\mathbf{a} $

也就是：

$ \boxed{
\|\mathbf{b}\|^2
=
\mathbf{a}^H\mathbf{C}^{-1}\mathbf{a}
} $

:::info
所以如果 $ \mathbf{C} $ 可逆：

$ \boxed{
\max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
}
=
\mathbf{a}^H\mathbf{C}^{-1}\mathbf{a}
} $

:::

---

#### 最优权重是什么？
取等号时，柯西-施瓦茨要求：

$ \mathbf{u}
\propto
\mathbf{b} $

也就是：

$ \mathbf{u}
\propto
\mathbf{C}^{-1/2}\mathbf{a} $

又因为：

$ \mathbf{u}
=
\mathbf{C}^{1/2}\mathbf{w} $

所以：

$ \mathbf{C}^{1/2}\mathbf{w}
\propto
\mathbf{C}^{-1/2}\mathbf{a} $

两边左乘：

$ \mathbf{C}^{-1/2} $

:::info
得到：

$ \boxed{
\mathbf{w}
\propto
\mathbf{C}^{-1}\mathbf{a}
} $

这就是最优线性合并权重。

:::

---

#### 如果 $ \mathbf{C} $ 不可逆
如果 $ \mathbf{C} $ 不可逆，把逆换成伪逆。

做特征分解：

$ \mathbf{C}
=
\mathbf{U}_r\boldsymbol{\Lambda}\mathbf{U}_r^H $

其中 $ \boldsymbol{\Lambda} $ 只包含非零特征值。

伪逆是：

$ \mathbf{C}^+
=
\mathbf{U}_r\boldsymbol{\Lambda}^{-1}\mathbf{U}_r^H $

**在 **$ \mathbf{a}\in\operatorname{Range}(\mathbf{C}) $** 的前提下**，**同样的白化推导只在有效子空间里做，**于是：

$ \boxed{
\max_{\mathbf{w}}
\frac{
|\mathbf{w}^H\mathbf{a}|^2
}{
\mathbf{w}^H\mathbf{C}\mathbf{w}
}
=
\mathbf{a}^H\mathbf{C}^+\mathbf{a}
} $

## 非均匀 pattern 的实验结果
### V1
旧的有效副本实验里，单个 pattern 的观测模型是：

$ y_b(m)
=
\frac{x}{\sqrt{N}}
H_b^{\mathrm{LoRa}}(m,K_0)
+
\eta_b(m) $

其中噪声项写成：

$ \eta_b(m)
=
\frac{1}{\sqrt{N}}
\sum_{p=0}^{N-1}
v[n_{b,p}]s_m^*[n_{b,p}] $

这里：

$ n_{b,p}
=
Rp+c_b[p] $

把所有 $ B $ 条 pattern 堆起来：

$ \mathbf{y}(m)
=
\frac{x}{\sqrt{N}}
\mathbf{h}^{\mathrm{LoRa}}(m,K_0)
+
\boldsymbol{\eta}(m) $

当K0=m时，代回：

$ \mathbf{y}(m)
=
x\sqrt{N}
\begin{bmatrix}
1\\
1\\
\vdots\\
1
\end{bmatrix}
+
\boldsymbol{\eta}(m) $

因此代码里的目标响应向量就是：

$ \boxed{
\mathbf{a}
=
\sqrt{N}
\begin{bmatrix}
1\\
1\\
\vdots\\
1
\end{bmatrix}
} $

也就是说，旧实验里的 $ \mathbf{a} $ 不是从 noisy 数据里估出来的，而是由理想 LoRa-corrected projection 直接得到的。

---

噪声协方差这边，代码先构造一个采样 / 投影矩阵：

$ \boldsymbol{\eta}(m)
=
\mathbf{S}(m)\mathbf{v}_{\mathrm{samp}} $

其中 $ \mathbf{v}_{\mathrm{samp}} $ 是：$ \mathbf{v}_{\mathrm{samp}}
=
\begin{bmatrix}
v[0]\\
v[1]\\
\vdots\\
v[NR-1]
\end{bmatrix} $，$ \mathbf{S}(m) $ 的第 $ b $ 行就是：$ \frac{1}{\sqrt{N}}
s_m^*[n_{b,p}] $。旧实验假设：$ \mathbb{E}
\left[
\mathbf{v}_{\mathrm{samp}}\mathbf{v}_{\mathrm{samp}}^H
\right]
=
\mathbf{I} $。于是：$ \mathbf{C}
=
\mathbb{E}
\left[
\boldsymbol{\eta}\boldsymbol{\eta}^H
\right]
=
\mathbf{S}(m)\mathbf{S}^H(m) $

真实实验里应该是：

$ \mathbf{C}
=
\mathbf{S}(m)\boldsymbol{\Sigma}_v\mathbf{S}^H(m) $

或者直接用 off-packet 估：

$ \widehat{\mathbf{C}}
=
\frac{1}{L}
\sum_{\ell=1}^{L}
\boldsymbol{\eta}^{(\ell)}
\boldsymbol{\eta}^{(\ell)H} $

---

模型本身就是：

$ \mathbf{y}
=
\mathbf{a}x+\boldsymbol{\eta} $

**代码固定：**

$ \mathbf{a}
=
\sqrt{N}\mathbf{1} $

于是 $ x $ 就表示相对于这个标准 LoRa 响应的复幅度。

有效副本数只看 pattern bank 的等效自由度，所以直接用：

$ \mathrm{effective\_replicas}
=
\frac{
\mathbf{a}^H\mathbf{C}^+\mathbf{a}
}{N} $

不需要估 $ x $。

如果真的要**从观测 **$ \mathbf{y} $** 里估 **$ x $**，才会用：**

$ \hat{x}
=
\frac{
\mathbf{a}^H\mathbf{C}^+\mathbf{y}
}{
\mathbf{a}^H\mathbf{C}^+\mathbf{a}
} $

如果非均匀 pattern 真创造了额外独立副本，我们应该看到：

$ \mathrm{effective\_replicas}
>
4 $

**在噪声是可加性高斯白噪声的前提下，实际算出来：**

$ \mathrm{fixed}
=
4.000000 $

$ \mathrm{basic}
=
4.000000 $

$ \mathrm{dither}
=
4.000000 $

$ \mathrm{search}
=
4.000000 $

$ \mathrm{basic\_only}
=
4.000000 $

$ \mathrm{random\_only}
\approx
3.91 $

所以结论是：

$ \text{非均匀 pattern 可以相干，但不能超过 OSR 的独立自由度。} $

更直白地说：

$ \text{信号项对齐了，但噪声项也高度相关。} $

额外 pattern 带来的表面增益，被：

$ \mathbf{C}^{+} $

扣掉以后，就不再是新的独立能量。

**然后还做了一堆乱七八糟的非均匀采样当成副本然后相干叠加的实验，只能说收益更加单薄。**

## 前言
另一种更贴近真实数据的做法是：直接用 off-packet 数据估计 pattern 输出噪声协方差：

$ \boxed{
\widehat{\mathbf{C}}
} $

$ \boldsymbol{\eta}^{(1)},
\boldsymbol{\eta}^{(2)},
\dots,
\boldsymbol{\eta}^{(L)} $

然后估计：

$ \widehat{\mathbf{C}}
=
\frac{1}{L}
\sum_{\ell=1}^{L}
\boldsymbol{\eta}^{(\ell)}
\boldsymbol{\eta}^{(\ell)H} $

---

因此更准确的判断应该是：

$ \boxed{
\mathbf{C}
=
\mathbf{S}\mathbf{S}^H
\text{ 只是白噪声理想模型下的协方差。}
} $

真实实验里应该使用：

$ \boxed{
\mathbf{C}
=
\mathbf{S}\boldsymbol{\Sigma}_{\nu}\mathbf{S}^H
} $

或者直接用 off-packet 噪声估计：

$ \boxed{
\widehat{\mathbf{C}}
} $

然后再检查：

$ \boxed{
\mathbf{a}
\in
\operatorname{Range}(\widehat{\mathbf{C}})
} $

$ \boxed{
\frac{
\left\|
\mathbf{a}
-
\widehat{\mathbf{C}}\widehat{\mathbf{C}}^+\mathbf{a}
\right\|
}{
\|\mathbf{a}\|
}
} $

如果这个残差接近 $ 0 $，说明 $ \mathbf{a} $ 基本落在 $ \widehat{\mathbf{C}} $ 的有效子空间里，可以继续使用：

$ \boxed{
\mathbf{a}^H\widehat{\mathbf{C}}^+\mathbf{a}
} $

# 实验3：OSR=4是否达到副本为4下的6db左右增益？
这一部分主要回答：

> 如果用 OSR $ =4 $ 四个 branch 相干合并，理论证据 SNR 比单 branch 高多少？
>

流程是这样：

---

## 从 off-packet 区域取噪声窗口
先从真实 IQ 里避开 packet 活跃区，取很多长度为 $ NR $ 的 off-packet 窗口。

第 $ \ell $ 个窗口 dechirp 后得到：

$ w^{(\ell)}[n] $

然后对每个窗口、每个候选 bin $ m $，算四个 fixed branch 输出：

$ Y_q^{(\ell)}[m],
\qquad
q=0,1,2,3 $

再做 Savaux 那个相位对齐：

$ \eta_q^{(\ell)}[m]
=
Y_q^{(\ell)}[m]
e^{-j2\pi qm/(NR)} $

于是每个窗口有一个四维噪声向量：

$ \boldsymbol{\eta}^{(\ell)}[m]
=
\begin{bmatrix}
\eta_0^{(\ell)}[m]\\
\eta_1^{(\ell)}[m]\\
\eta_2^{(\ell)}[m]\\
\eta_3^{(\ell)}[m]
\end{bmatrix} $

然后估计真实噪声协方差：

$ \widehat{\mathbf{C}}[m]
=
\frac{1}{L-1}
\sum_{\ell=1}^{L}
\left(
\boldsymbol{\eta}^{(\ell)}[m]
-
\bar{\boldsymbol{\eta}}[m]
\right)
\left(
\boldsymbol{\eta}^{(\ell)}[m]
-
\bar{\boldsymbol{\eta}}[m]
\right)^H $

其中：

$ \bar{\boldsymbol{\eta}}[m]
=
\frac{1}{L}
\sum_{\ell=1}^{L}
\boldsymbol{\eta}^{(\ell)}[m] $

---

## 如果四个 branch 噪声独立，理论增益应接近 6.02 dB
如果四个 branch 噪声完全独立同方差，那么 $ \widehat{\mathbf{C}}[m] $ 近似对角。

此时 OSR $ =4 $ 合并增益接近：

$ 10\log_{10}4
=
6.02\ \mathrm{dB} $

但实测 $ \widehat{\mathbf{C}}[m] $ 不是这样。

**branch 之间有相关性，所以等权相干合并的噪声方差是：**

$ \operatorname{Var}
\left[
\sum_{q=0}^{3}
V_q[m]
\right]
=
\mathbf{1}^H
\widehat{\mathbf{C}}[m]
\mathbf{1} $（1是全1向量）

## OSR=4 合并 SNR
理想信号项四路同相，所以信号幅度从单 branch 的 $ \sqrt{N} $ 变成：

$ 4\sqrt{N} $

于是 OSR $ =4 $ 合并 SNR 是：

$ \mathrm{SNR}_{\mathrm{OSR4}}[m]
=
\frac{
16N
}{
\mathbf{1}^H
\widehat{\mathbf{C}}[m]
\mathbf{1}
} $

单 branch $ q $ 的 SNR 是：

$ \mathrm{SNR}_{q}[m]
=
\frac{
N
}{
\widehat{C}_{qq}[m]
} $
