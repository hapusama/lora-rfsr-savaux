# 弱包检测与 SFD 帧定位逻辑

这个版本把“检测到疑似前导码”和“确定一帧的物理边界”拆成两个阶段。

第一阶段只负责在 raw IQ 上找到可能存在 LoRa preamble 的粗位置；第二阶段在粗位置附近搜索 sync word 和 SFD，由 SFD 反推出前导码起点，并给出 payload 起点。

---

## 1. 最简输入参数

| 参数 | 含义 |
|------|------|
| `SF` | 扩频因子 |
| `BW` | LoRa 带宽 |
| `samp_rate` | IQ 采样率 |
| `sync_word` | LoRa sync word，默认 `0x34` |
| `preamble_len` | 已知前导码 upchirp 数 |
| `win_chirps` | 每个检测窗口包含多少个 chirp |
| `hop_samples` | 滑动窗口步长 |
| `min_periodic_peaks` | 至少出现多少次周期性 peak 才认为检测成功 |
| `bin_tol` | 检测阶段 peak bin 允许偏差 |
| `frame_search_samples` | SFD 定位时每个整 chirp 偏移附近的细搜索半径 |
| `frame_symbol_search_span` | SFD 定位时额外搜索前后多少个整 chirp |

当前逻辑不先引入能量阈值。每个窗口都强制取一个最大 peak bin，然后先看这个 peak bin 是否呈现 LoRa preamble 的周期性重复特征。

---

## 2. 整体流程

```text
raw complex64 IQ
  ↓
不降采样，保留 os_factor 过采样 chirp 长度
  ↓
滑动窗口扫描
  ↓
每个窗口包含 win_chirps 个 chirp
  ↓
每个 chirp 分别 dechirp + FFT
  ↓
窗口内 FFT 能量按 bin 累加
  ↓
取 peak bin
  ↓
连续窗口 peak bin 稳定超过 min_periodic_peaks
  ↓
输出 coarse detection event
  ↓
在 coarse event 附近建立候选符号边界 q
  ↓
对每个 q：
    计算 preamble + sync word 的 upchirp-dechirp peak 序列
    计算 SFD 两个完整 downchirp 的 downchirp-dechirp peak 序列
  ↓
寻找：
    稳定 preamble upchirp
    + sync word 两个符号
    + SFD 两个完整 downchirp
  ↓
找到 SFD 起点
  ↓
payload_start = SFD_start + 2.25 * Ns
```

注意：第一阶段输出的 `detected_start_sample` 只是粗检测事件起点，不是前导码真实起点。真正用于后续同步估计的是第二阶段输出的 `located_preamble_start_sample`。

---

## 3. 滑窗前导码粗检测

LoRa preamble 是连续的相同 upchirp。

如果某个窗口真正覆盖了 preamble 区域，那么窗口内多个 chirp 经过 dechirp+FFT 后，应该在相同或接近的 FFT bin 上出现峰值。

对第 `i` 个滑动窗口：

- 截取长度为 `win_chirps` 个 chirp 的 IQ 数据；
- 把窗口切成 `win_chirps` 段；
- 每段分别做 dechirp+FFT；
- 把这些 FFT 幅度平方按 bin 累加；
- 找到累加能量最大的 bin；
- 记录这个窗口的 peak bin。

公式为：

$$E_i[k] = \sum_{\ell=0}^{L_w-1} |Z_{i,\ell}[k]|^2$$

其中：

$$L_w = \text{win\_chirps}$$

然后取：

$$k_i^\star = \arg\max_k E_i[k]$$

如果连续若干个窗口满足：

$$d_{\mathrm{circ}}(k_{i+r}^\star, k_i^\star) \le \Delta k$$

且数量达到：

$$R \ge \text{min\_periodic\_peaks}$$

则认为检测到一个粗 preamble event。

这里使用循环 bin 距离 `d_circ`，避免 `0` 和末尾 bin 被误认为相距很远。

---

## 4. SFD 帧定位

粗检测只说明“这里像前导码”，不能保证已经知道前导码开始和结束。SFD 定位阶段负责确定真实帧边界。

设：

$$N_s = \frac{samp\_rate}{BW} \cdot 2^{SF}$$

这里 `Ns` 是过采样后的 chirp sample 数。

对粗位置附近的候选符号边界 `q`，检查下面的结构：

```text
q
  -> preamble_len 个 upchirp
  -> 2 个 sync word upchirp
  -> 2 个完整 SFD downchirp
  -> 0.25 个 SFD downchirp
  -> payload
```

### 4.1 upchirp peak 序列

对：

$$q + sN_s,\quad s=0,\ldots,preamble\_len+1$$

做 upchirp 解调，也就是乘本地 downchirp 后做 FFT。

前 `preamble_len` 个符号应该具有稳定的参考 bin：

$$k_{\mathrm{pre}}$$

sync word `0x34` 在 gr-lora_sdr 中映射成两个符号：

```text
sync1 = ((0x34 & 0xF0) >> 4) << 3 = 24
sync2 = (0x34 & 0x0F) << 3        = 32
```

因此 sync word 的相对 bin 应满足：

$$d_{\mathrm{circ}}((k_{\mathrm{sync1}} - k_{\mathrm{pre}}) \bmod N_s, 24) \le \Delta k_{\mathrm{sync}}$$

$$d_{\mathrm{circ}}((k_{\mathrm{sync2}} - k_{\mathrm{pre}}) \bmod N_s, 32) \le \Delta k_{\mathrm{sync}}$$

### 4.2 SFD downchirp peak 序列

SFD 起点为：

$$SFD\_start = q + (preamble\_len + 2)N_s$$

对两个完整 downchirp：

$$SFD\_start,\quad SFD\_start + N_s$$

做 downchirp 解调，也就是乘本地 upchirp 后做 FFT。

两个 SFD downchirp 的 peak bin 应该稳定：

$$d_{\mathrm{circ}}(k_{\mathrm{sfd1}}, k_{\mathrm{sfd2}}) \le \Delta k_{\mathrm{sfd}}$$

### 4.3 payload 起点

LoRa SFD 是 `2.25` 个 downchirp，所以：

$$payload\_start = SFD\_start + 2.25N_s$$

也等价于：

$$payload\_start = q + (preamble\_len + 4.25)N_s$$

## 5. 当前脚本实现

主入口：

```text
scripts/run_weak_sync_chain.py
```

核心模块：

```text
weak_decoder/synchronization/preamble_detector.py  # 滑窗粗检测
weak_decoder/synchronization/frame_locator.py      # sync word + SFD 帧定位
weak_decoder/initial_state.py      # 初始 CFO/STO/SFO 搜索
```

当前链路输出中的关键字段：

| 字段 | 含义 |
|------|------|
| `detected_start_sample` | 滑窗粗检测事件起点，不是精确前导码起点 |
| `aligned_start_sample` | 粗 upchirp 能量对齐结果，只作为 SFD 搜索中心 |
| `frame_valid` | sync word + SFD 规则是否通过 |
| `located_preamble_start_sample` | SFD 定位反推得到的前导码起点 |
| `located_sfd_start_sample` | 找到的 SFD 起点 |
| `located_payload_start_sample` | 由 SFD 起点加 `2.25Ns` 得到的 payload 起点 |
| `sync1_distance` / `sync2_distance` | 两个 sync word 相对 bin 的误差 |
| `sfd_bin_distance` | 两个完整 SFD downchirp peak bin 的距离 |

## 7. 当前边界

- 这个阶段仍然没有对整段 IQ 做 CFO/SFO 补偿，只做边界搜索和峰值结构验证。
- `frame_symbol_search_span` 是必要的，因为粗检测/粗对齐可能落在前导码内部某个 chirp，而不是第一个 preamble chirp。
- 弱噪声场景下可以适当放宽 `frame_sync_bin_tol` 和 `frame_sfd_bin_tol`，但 clean/high-SNR 数据上应优先要求距离为 0 或很小。
- 后续 payload peak 搜索应优先使用 `located_payload_start_sample`，而不是初始状态估计里未经过 SFD 校验的 `payload_start_sample`。
