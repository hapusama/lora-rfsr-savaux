你现在不是“问题太多无从下手”，而是把 **三个性质完全不同的问题混在了一起**。先拆开，顺序就很清楚了。你这份记录其实已经给出了不少关键证据。

# 一、先解释目前看似矛盾的结果

你现在有两类实验：

### CRC 完整链

[
\text{native 1M}
\rightarrow
\text{先加噪}
\rightarrow
\text{降采样到 250k}
\rightarrow
\text{RFSR}
\rightarrow
\text{同步解码}
]

这里旧 g24 有明显提升：

[
10/15,\ 6/15,\ 4/15.
]

### Savaux SER 链

[
\text{干净 250k}
\rightarrow
\text{RFSR}
\rightarrow
\text{同步}
\rightarrow
\text{RFSR 输出后再加噪}
\rightarrow
\text{Savaux}
]

这里 RFSR 比原生 1 MHz 差很多。

这两个结果并不矛盾，它们很可能说明：

[
\boxed{
\text{当前 RFSR 的主要收益是“前端去噪”，而不是恢复出了能供 Savaux 合并的高采样信息。}
}
]

第一种实验中，噪声在 RFSR 前面，网络可以把一部分噪声滤掉，因此 CRC 可能改善。

第二种实验中，噪声在 RFSR 后面才加入，RFSR 完全没有机会去噪。此时只考察它生成的干净高采样波形本身是否准确。结果显示：

[
\text{RFSR payload margin}
\approx 10\text{ dB},
\qquad
\text{native}
\approx17\text{ dB},
]

说明它生成的 chirp 已经存在明显的相位误差或频谱扩散。

因此，目前不能说：

> RFSR 恢复高采样率后帮助了 Savaux。

更准确的是：

> RFSR 可能是一个有用的低采样去噪器，但目前不是一个足以支持 Savaux 的高保真 polyphase 重建器。

# 二、现在最核心的三个问题

## 问题 1：训练目标与 Savaux 目标不一致

当前 g100 微调使用：

[
x=\text{真实 OTA 的 }250\text{kS/s},
\qquad
y=\text{同一次真实 OTA 的 }1\text{MS/s}.
]

这个训练对在坐标上完全正确，但损失只要求：

[
\widehat y\approx y.
]

它没有显式要求：

* dechirp 后正确峰更集中；
* FFT 泄漏更小；
* 四个 polyphase branch 相位关系正确；
* Savaux 正确峰 margin 增大。

因此即使时域 loss 下降，也可能出现：

[
\text{时域误差变小}
\quad\text{但}\quad
\text{dechirp 峰变散}.
]

你普通 FFT 和 Savaux 都显示 margin 下降，已经说明问题发生在 RFSR 输出，而不是 Savaux 实现。

---

## 问题 2：g100 比 g24 差，可能是微调导致遗忘

你真正的独立样本量不是：

[
100\times 8=800,
]

而更接近：

[
100\text{ 个物理包}.
]

同一个物理包的 8 个 ADC/polyphase view 高度相关，不能当成 8 个真正独立样本。

g24 比 g100 的峰值 margin 更高，可能意味着：

[
\boxed{
\text{微调越久，模型越适应真实 OTA 噪声，同时越忘记合成预训练学到的 clean chirp 先验。}
}
]

这就是典型的微调遗忘。received-to-received 标签本身包含噪声，模型训练久了可能逐渐学着重现真实接收中的噪声、滤波失真和局部波动，而不是继续输出干净、集中的 chirp。

所以“数据更多反而变差”并不一定是 payload 记忆，而更可能是：

* 真实标签含噪；
* 视图高度相关；
* 全模型一起更新；
* 没有混入 synthetic clean 数据；
* 没有约束模型不要偏离预训练权重。

---

## 问题 3：MRC 所需的信息未必能够从单条低采样观测恢复

这是最根本的问题。

原生 1 MHz 有四条真实采样 branch：

[
y_q[n]=y[4n+q],
\qquad q=0,1,2,3.
]

它们是 ADC 在不同时间位置得到的真实观测。

RFSR 的四条 branch 则全部由同一条 250 kHz 输入生成：

[
\widehat y_q=f_q(x).
]

所以它们的误差很可能高度相关：

[
e_0\approx e_1\approx e_2\approx e_3.
]

即使生成了四倍样点数，也不等于获得了四条独立观测。Savaux 的合并收益依赖的是：

[
\text{多个具有互补噪声和相位信息的真实观测},
]

而不是单纯有四倍数量的数值。

不过你现在的 Savaux SER 实验是在 RFSR 后重新加入 1 MHz 噪声，因此它已经人为提供了 branch 噪声差异，结果仍然很差。这说明当前首要问题还不是信息论极限，而是：

[
\boxed{
\text{RFSR 生成的 clean chirp 本身就不够准确。}
}
]

所以先诊断波形重建，再讨论 MRC 上限。

---

# 三、你现在应当从哪里开始

不要先改 reference 标签，也不要先换大网络。按下面顺序做四个诊断。

## 第一步：统一评估口径

固定：

* 同一个 held-out test split；
* 同一个 checkpoint 集；
* 同一批物理包；
* 同一组噪声 seed；
* 同一种同步口径。

比较五条链：

[
\begin{aligned}
&250\text{k raw},\
&\text{interpolation},\
&\text{pretrained-only RFSR},\
&\text{g24 RFSR},\
&\text{g100 RFSR},\
&\text{native }1\text{M}.
\end{aligned}
]

分别跑两种噪声位置：

### A：噪声在 RFSR 前

用于判断去噪能力：

[
\text{add noise}
\rightarrow
250k
\rightarrow
RFSR.
]

### B：噪声在 RFSR 后

用于判断纯升采样保真度：

[
250k
\rightarrow
RFSR
\rightarrow
\text{add noise}.
]

只要这两个表出来，你就能明确区分：

[
\text{denoising gain}
\quad\text{和}\quad
\text{sampling-reconstruction gain}.
]

---

## 第二步：直接检查四个 polyphase branch 是否恢复正确

不要只看整包 MSE。

对于输出：

[
\widehat y[n],
]

低采样输入来自第 (q) 个相位：

[
x[n]=y[4n+q].
]

应分别计算：

### 已观测相位误差

[
E_{\mathrm{obs}}
================

\frac{
|\widehat y[q::4]-x|_2^2
}{
|x|_2^2
}.
]

理论上这一项应接近零。最好在模型输出后直接硬覆盖：

[
\widehat y[q+4n]=x[n].
]

### 未观测相位误差

对于 (p\neq q)：

[
E_p
===

\frac{
|\widehat y[p::4]-y_{\mathrm{native}}[p::4]|*2^2
}{
|y*{\mathrm{native}}[p::4]|_2^2
}.
]

真正决定升采样能力的是这三个未观测 branch，而不是整包平均 MSE。

### 复数相关性

[
\rho_p
======

\frac{
|\widehat{\mathbf y}_p^H\mathbf y_p|
}{
|\widehat{\mathbf y}_p|
|\mathbf y_p|
}.
]

### 相位误差

[
\Delta\phi_p[n]
===============

\angle
\left(
\widehat y_p[n]y_p^*[n]
\right).
]

如果幅度误差不大，但相位误差随时间漂移，dechirp-FFT 峰一定会扩散。

---

## 第三步：直接比较 dechirp 后的 branch 误差

对于每个正确符号 (k)，计算原生与预测的 branch 谱：

[
Z_q^{\mathrm{native}}(m),
\qquad
\widehat Z_q(m).
]

重点看：

[
\widehat Z_q(k)
\quad\text{和}\quad
Z_q^{\mathrm{native}}(k)
]

之间的：

* 幅度误差；
* 相位误差；
* branch 间相对相位；
* 正确峰能量占总能量比例；
* 正确峰与第二峰 margin。

进一步定义 branch 误差：

[
e_q
===

\widehat Z_q(k)-Z_q^{\mathrm{native}}(k).
]

估计误差协方差：

[
\mathbf C_e
===========

\mathbb E
\left[
\mathbf e\mathbf e^H
\right].
]

如果四条预测 branch 的误差高度相关，就会看到 (\mathbf C_e) 接近 rank-1。此时即使单条 branch 尚可，Savaux 合并也很难获得额外收益。

---

## 第四步：检查 finetune 是否破坏了预训练能力

对以下 checkpoint：

* pretrained-only；
* g24；
* g100；

同时在两套验证集上评估：

### synthetic clean validation

测基础插值/去噪能力。

### held-out OTA received validation

测真实域适配能力。

可能出现的结果是：

| 模型         | synthetic |                OTA |
| ---------- | --------: | -----------------: |
| pretrained |         好 |                 一般 |
| g24        |        略降 |                 提升 |
| g100       |      明显下降 | loss 更低但 Savaux 更差 |

如果这样，就基本确认是 catastrophic forgetting。

此时才考虑：

[
\boxed{
\text{synthetic 与 OTA 混合微调}
}
]

例如一个 batch 中：

[
50%\text{ synthetic clean}
+
50%\text{ OTA received}.
]

或者加入预训练权重约束：

[
\mathcal L_{\mathrm{L2SP}}
==========================

\lambda
|\theta-\theta_{\mathrm{pre}}|_2^2.
]

也可以只更新最后两层，先冻结前面的插值残差特征。

---

# 四、目前暂时不要做的事情

## 不要立刻使用 synthetic reference 微调

你现在：

[
x=\text{真实 OTA},
\qquad
y=\text{理想 reference}
]

存在：

* 幅度差；
* CFO；
* STO/SFO；
* 初相位；
* 信道；
* 包内时间轴误差。

修改 FFT 归一化只能解决 loss 数值很大，不能让这组标签自动变正确。

因此 `reference` 模式先作为单独研究分支，不要拿来修当前主线。

## 不要先增大 stride

stride 会进一步降低时间分辨率，和精确恢复 missing samples 的目标相反。

需要扩大感受野时，应优先考虑：

* dilation；
* TCN；
* 多尺度卷积；
* 小窗口分块；
* residual blocks。

不是简单把 stride 调大。

## 不要先换 U-Net 或 Transformer

在不知道错误来自：

* 幅度；
* 相位；
* branch 相对关系；
* finetune 遗忘；
* loss 错位；

之前，大模型只会让问题更难解释。

# 五、根据诊断结果怎么决定下一步

## 情况 A：pretrained-only 比 g24/g100 更好

说明 finetune 有害。

下一步：

[
\text{混合 synthetic/OTA 微调}
+
\text{冻结部分网络}
+
\text{更小学习率}
+
\text{L2-SP}.
]

## 情况 B：RFSR 的时域 NMSE 更好，但 FFT margin 更差

说明损失与任务不一致。

下一步在保持时域损失的同时加入：

[
\mathcal L_{\mathrm{dechirp}}
=============================

\sum_q
|
\widehat Z_q-Z_q^{\mathrm{native}}
|_1,
]

或正确峰 margin loss。

## 情况 C：RFSR 连未观测 phase 都恢复不好

说明网络结构能力不足。

这时才值得把四层 CNN 换成 dilated TCN 或多尺度网络。

## 情况 D：波形和 branch 都恢复不错，但 Savaux 仍无提升

说明限制来自：

[
\text{单条低采样输入无法创造真实多观测多样性}.
]

那就应该停止追求“RFSR 生成 branch 后做 MRC”，转向：

* 低采样 task-driven 解调；
* 利用重复前导码形成真实多视图；
* 直接预测 Savaux/dechirp 统计量。

---

# 现在最小的下一步

你当前最值得马上跑的不是新训练，而是下面这个表：

| 方法              | observed-phase NMSE | missing-phase NMSE | complex correlation | 普通 FFT margin | Savaux margin |
| --------------- | ------------------: | -----------------: | ------------------: | ------------: | ------------: |
| interpolation   |                     |                    |                     |               |               |
| pretrained-only |                     |                    |                     |               |               |
| g24             |                     |                    |                     |               |               |
| g100            |                     |                    |                     |               |               |
| native          |                   0 |                  0 |                   1 |               |               |

只用干净 held-out OTA，不加任何额外噪声。

这个表会直接告诉你：到底是 **微调毁了模型、网络恢复不了 missing phase、还是只差任务损失**。在这张表出来之前，继续改 reference、loss 或网络结构都会很容易绕回原点。
