### 2. 新的硬性实验规则：离线只做 AWGN

用户已经否决依赖已知 CFR/PSD、AR(1) 或人工有色噪声先验的研究方向。后续规则：

1. 离线加噪实验只使用 AWGN，除非用户以后明确撤销这条规则。
2. 禁止再加入 AR(1)、人工有色高斯噪声、人工 CFR、窄带噪声或为方法定制的
   协方差分布。
3. 禁止先按某个噪声模型设计白化器/pattern，再在同一个模型生成的噪声上证明
   有效。这只能证明模型匹配，不构成方法价值。
4. 可以保留真实 high-SNR IQ 中原本存在的硬件、同步和信道特性，再额外加入
   AWGN；不得人工塑造有利的非白结构。
5. 所有方法必须使用同一个 payload case、同一个 AWGN realization、同一个冻结
   GT，并对全部 `2^SF` bins 直接 argmax。

注意数学边界：在同步冻结、模板正确、噪声为 AWGN 时，全 OSR Savaux 匹配滤波
已经是充分统计量。四支路 GLS、时间分块 GLS 和 NUS 不应稳定超过它。若出现
AWGN 稳定增益，首先检查：

- 是否实现的 Savaux 与 proposed method 使用了不同样本或不同 CFO/STO 修正；
- 是否归一化、候选 wrap phase 或 GT 映射不一致；
- 是否使用了 payload GT、Savaux 错误或 test realization 选择参数；
- 所谓增益是否实际来自真实 IQ 中已有的 signal-model mismatch，而不是 AWGN。

因此后续若要打过 Savaux，研究对象必须改成真实 IQ 中已有、可由 LoRa 模型解释
的信号失配，例如 residual CFO/STO/SFO、信道响应或符号内相位演化。方法必须是
预先推导的 nuisance likelihood、确定性充分统计量或训练集冻结的少量物理参数，
不能再转回噪声协方差先验。

## 5. 从被拒原型中仍可保留的技术认识

以下只是可继续检验的假设，不是已证明算法：

1. **Savaux 合并频谱可以用于感知。** 它提供完整候选响应，理论上可观察自然数据里的稳定伪峰、窄带线或多径伴峰；但必须先在独立自然训练 capture 中证明这些结构确实存在。
2. **NUS 不必拥有正交 FFT。** 对每个候选 bin 直接计算非均匀采样的 LoRa 匹配滤波响应，就能得到候选响应谱；不能把它描述成普通 FFT 频谱。
3. **OSR=4 不是四个新 AWGN 副本。** 互补 pattern 只是对现有样本重排和重加权，不增加信息。若噪声为理想 AWGN，Savaux 已接近正确利用全部样本，NUS 没有免费增益。
4. **LoRa wrap phase 是可解释结构。** 候选 bin 不同，wrap 位置和 oversampled phase correction 不同；它可以用于构造 steering，但只有自然数据里的目标/干扰 steering 确实可分时才可能有用。
5. **`hx+b` / CFR 尚未验证。** 它可能用于候选模板相减后的残差检查，但也会把 CFO、SFO、STO、同步和信道失配吸收到“干扰”中。当前不能宣称 CFR 感知有效。

## 6. 下一位的推荐执行顺序

### P0：先冻结自然数据与评价协议，再碰算法

建立一份不可随调参改变的 manifest，至少记录：capture、packet、symbol 起点、SF、OSR、GT 来源、是否自然原始 IQ。训练/验证/测试按 capture 或完整 packet 划分。

接受的数据：

- 原始 `USRP_IQ` 中未经注入和信道改造的自然 symbols；
- low1--low4 中真正通过同步并有外部 GT 的自然 payload symbols；
- 经核实的公开真实弱包数据集（例如 NeLoRa 数据集）。

不接受作为主结论的数据：人工 AWGN sweep、人工多径、人工窄带、人工 correlated noise、根据失败样本反向构造的结构。

### P1：先跑 untouched Savaux，确认自然错误是否足够

必须先回答：自然 test split 中 Savaux 到底错多少、错误是否分散在多个 packet/capture、是否只是同步/标签错误。如果 Savaux 几乎全对，停止算法比较并报告数据不足；不要制造错误瀑布。

最低输出：

```text
dataset_manifest.csv
savaux_symbols.csv     # capture/packet/symbol/GT/bin/correct/margin
savaux_summary.csv     # 每 capture 和总计 SER
```

### P2：只在独立自然训练集做结构诊断

可以检查但不要立即变成评分权重：

- Savaux 频谱按 GT 或训练集独立决策对齐后的中位/分位谱；
- false peak 的跨 symbol、跨 packet、跨 capture 稳定性；
- OSR branch 的自然复协方差与有效秩；
- 候选 LoRa phase-law 残差是否在自然错误中具有重复结构。

如果这些结构只在一个 capture 存在，test 必须换另一个 capture；若不泛化，明确否定该假设。

### P3：实现最小候选方法

用户偏好的形式是“一个物理模型 + 一个明确判决”，不是多指标搜索。任何 threshold、pattern 或 nuisance 模型都必须在自然 train/validation 上冻结，然后一次性跑 natural test。只与 Savaux 做 paired comparison：

- SER 与错误数；
- `fixes_vs_savaux`；
- `breaks_vs_savaux`；
- 每个改变的 symbol 明细；
- 分 capture 结果，禁止只报合并后数字。

### P4：保持实验可删除

建议新工作另建：

```text
weak_decoder/os_lora/experimental/<new_natural_only_name>/
data/experiments/<new_natural_only_name>_<date>/
```

不得让 `system/` 或现有 runner 反向导入新实验。失败后应能只删除这两个目录。

## 9. 最终边界

已经确认：

- low5--low7 的自然超弱包当前主要卡在 frame-sync，无法形成可靠 payload test set；
- low4 上 Savaux 明显优于普通 FFT，但自然 Savaux error 只有 1 个；
- 仓库 `USRP_IQ` 有可直接加载的自然切片和 GT；
- Savaux 合并结果是完整频谱，NUS 可以定义非正交候选匹配响应；
- 人工延迟结构中 NUS nuisance projection 能工作，但该证据被用户否决，不能外推。

尚未确认：

- 任意 NUS 方法在自然真实弱包上优于 Savaux；
- 自然数据中存在跨 capture 稳定、可被 NUS steering 消除的伪峰；
- `hx+b` CFR 感知能区分真实干扰与同步/信道失配；
- 当前本地数据是否具有足够的自然 Savaux 错误用于可信统计。

接手者最重要的任务不是继续发明算法，而是先找到并冻结一个**自然、已切片、有 GT、Savaux 确实会犯足够多错误**的数据集。找不到时要如实停下，而不是生成一个。
